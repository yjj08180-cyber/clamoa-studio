# CLAMOA Feed Studio

클라모아 팀이 키워드를 조사하고 컷을 기획·생성·검수하는 한국어 웹앱입니다. 첫 실행에 2027 S/S 실제 이미지 20컷과 시즌 보드가 열립니다.

## 실행

Node.js 24 LTS 환경에서 아래 명령을 실행합니다.

```sh
npm ci
npm run dev
```

[로컬 스튜디오 열기](http://127.0.0.1:3000). 로컬 작업과 업로드 파일은 서버 재시작 후에도 `.clamoa/`에 남습니다.

- **샘플 살펴보기** — 홈에서 *Celestial Handle*을 열고 **근거와 제작 기록**을 펼칩니다. 컬러 전망 원문, 가죽 음각 지시, 채택된 버전을 확인할 수 있습니다. 기존 이미지의 실행 프롬프트는 원본 기록의 보유 여부를 표시합니다.
- **새로 제작하기** — **콘텐츠 생성하기**에서 키워드, 원하는 느낌이나 컷 수를 한 번에 적습니다. 공개 원문과 Pinterest 핀을 찾아 근거가 있는 컷의 초안을 자동으로 만듭니다. 확보한 Pinterest 이미지는 조명·색·질감을 분석한 뒤 클라모아 워드마크와 함께 이미지 생성에 전달합니다. 사용한 핀과 관찰 내용은 컷별로 기록합니다. Pinterest 이미지가 확보되지 않으면 연결 상태를 표시하고 확보한 다른 자료로 제작을 이어갑니다. 참고 파일과 제작 방식은 제작 폼에서 펼칠 수 있습니다. 수동 제작을 선택하면 자료와 고정 번호 컷을 직접 등록하고, 프롬프트를 복사해 만든 이미지를 같은 컷의 버전으로 업로드할 수 있습니다.
- **무드보드와 제작 근거** — 기존 컷의 번호를 기준으로 새 시리즈를 시작하거나 선호·피할 컷과 이유를 모읍니다. 무드 링크와 이미지에 빛·색·질감·프레이밍을 기록하고, 선정 근거와 함께 컷에 연결합니다. 콘텐츠 풀에서는 컷 번호로 채택본과 보류본을 찾을 수 있습니다.
- **초안 수정하기** — 초안 아래에 바꿀 내용을 적으면 기존 이미지와 워드마크를 바탕으로 새 버전이 생성됩니다. 원래 브리프, 레퍼런스와 수정 요청은 프로젝트 및 제작 기록에 보관됩니다.
- **배열 내보내기** — **피드 편집**에서 새 배열을 만들고 콘텐츠 풀의 컷을 추가합니다. 배열을 저장하거나 인덱스 JPG·ZIP을 내려받습니다. 컷 검수 화면에서 게시용 JPG 한 장도 받을 수 있습니다.

## OpenAI 연결

`.env.example`을 `.env.local`로 복사하고 서버의 `OPENAI_API_KEY`를 설정한 뒤 앱을 재시작합니다. 리서치는 Responses API 웹 검색과 PDF 페이지·팀 메모를 사용합니다. 무드 사진은 빛·색·질감·프레이밍으로 해석합니다. 이미지 생성은 컷별 프롬프트와 선택한 워드마크를 Images API로 전송합니다.

기본 이미지 모델은 `gpt-image-2.6-sunburst`입니다. 첫 연결 후 목표 수량 1인 브리프로 리서치와 생성을 실행해 해당 조직의 모델 권한을 확인하세요. 성공 시 원본은 1152×1440 PNG, 게시본은 1080×1350 JPG입니다. 생성 거부·한도 초과·모델 권한 오류는 해당 작업에 기록됩니다. PDF 자동 인용은 텍스트를 읽을 수 있는 페이지를 지원합니다. 비율이 다른 수동 업로드는 원본을 보존하고 게시본 여백을 맞춥니다.

## 팀 설치와 검증

팀 서버는 Supabase 인증, 비공개 Storage와 Postgres를 사용합니다. DB의 작업 대기열과 워커가 요청 중복을 방지하고 실행 결과를 버전으로 연결합니다. 관리자 초대, 이메일 템플릿, SQL 마이그레이션과 워커 실행 방법은 [팀 서버 설치 안내](docs/server.md)에 있습니다.

이메일로 한 번 인증하면 브라우저에서 로그인 세션을 자동으로 갱신합니다. 로그인 중 **스튜디오 설정 → 팀 · 연결 → 내 스튜디오 비밀번호**에서 비밀번호를 저장하면 새 브라우저에서도 이메일과 비밀번호로 로그인할 수 있습니다. 필요하면 이메일 링크로 다시 인증할 수 있습니다.

`npm run check:connections`로 OpenAI 모델 권한과 Supabase 연결을 점검할 수 있습니다. 실제 리서치와 이미지 한 컷 생성은 `npm run check:connections -- --smoke-openai`로 확인합니다.

```sh
npm test
npm run typecheck
npm run build
npm run test:browser
npm start
```

브라우저 검증에는 Chromium 또는 Chrome이 필요합니다. Chromium을 설치하려면 `npx playwright install chromium`을 실행합니다.

테스트는 실제 샘플 JPG로 ZIP의 규격과 배열 순서를 검사합니다. OpenAI와 이메일 호출은 테스트용 응답으로 검증합니다. SS27 컬러 근거는 [WGSN·Coloro 시즌 발표](https://www.wgsn.com/en/wgsn/press/press-releases/wgsn-and-coloro-reveal-colour-year-2027-luminous-blue-and-s-s-27-key)에 연결됩니다.
